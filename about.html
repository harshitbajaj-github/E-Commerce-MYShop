About MyShop

Multi-Page E-Commerce Website built using HTML, CSS, JavaScript & Bootstrap

🚀 Key Features

  • Multi-page layout with Home, Products, About, Contact, Cart, Login, Signup
  • Responsive design using Bootstrap 5
  • Dark Mode toggle for enhanced user experience
  • Interactive product cards with Add to Cart functionality
  • Login / Signup UI with dynamic Logout button
  • Sticky professional footer with social links and contact info

🎯 Purpose

MyShop is created for learning and showcasing **front-end web development skills**. It demonstrates a complete workflow of a shopping website with reusable components, responsive design, and user interaction. Perfect for adding to **resume or portfolio**.

🛠 Technologies Used

  • HTML5: Structure & layout
  • CSS3: Styling & responsive design
  • Bootstrap 5: Components & responsive grid
  • JavaScript: Dark mode, Add to Cart, Login/Logout
  • LocalStorage: Persistent cart & session management

💡 Learning Outcomes

  • Developed a professional multi-page website
  • Built responsive UI using Bootstrap
  • Implemented interactive cart functionality with JavaScript
  • Created reusable navbar and footer for all pages
  • Simulated authentication system using LocalStorage
